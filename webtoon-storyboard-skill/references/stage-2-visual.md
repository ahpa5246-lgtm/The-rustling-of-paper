# Stage 2 contract — visual directing after explicit editorial approval

Read the approved `editorial-plan.md`, the current chapter scene map and continuity ledger. Check the approved revision ID; if editorial is pending or materially changed, stop and return to Stage 1. Use the source and all seven course principles.

## Visual decision matrix (one row per Pxx)
For every approved panel ID:
- **Narrative job and evidence:** one-sentence function and exactly which fact/gesture/text must be legible. Preserve whether a fact is not yet disclosed.
- **Shot size:** extreme wide, wide, medium long, medium, medium close, close, extreme close, or justified variant. State what context is lost/gained.
- **View:** eye-level, high/low, overhead, tilted when useful; front, profile, rear or over-the-shoulder; POV if applicable. Do not assign fixed emotional meanings to angles.
- **Blocking/geography:** subject positions and screen direction, where limbs/props are, visible action at the chosen instant, continuity with adjacent shots and previous scene.
- **Composition:** focal target, second/third attention priority, contrast, relative scale, placement, isolation, lines/gaze, negative space **inside** the panel and expected text/bubble space. A screen message cannot be described as legible if the visual plan makes it too small/occluded.
- **Scroll and transition:** type of inferred jump/closure, whether next panel should be visible in the same viewport or withheld, relative gutter strategy (short / moderate / intentionally long with reason). No fixed pixel count without an actual scroll mockup.
- **Provisional panel aspect/height:** for a 700px-wide sketch strip; preserve flexibility for revisions. Never confuse apparent shot size with final panel dimensions.
- **Known failure / alternative:** how the image could fail and one grounded way to fix it.

## Scene-level decisions
Produce an ordered vertical strip plan with panel IDs and provisional group boundaries. Choose pacing by reader questions and reveal placement; keep temporal/spatial clarity. When a dramatic reveal spans a segmentation seam, place the split where it preserves approved timing; never split the *inside* of a panel. Confirm whether speech or narration is placed in bubbles, legends or outside the drawing; keep exact supplied text when plot-critical.

## Example of linked reasoning
Approved function: "reader sees Samer wrote نعم but has NOT sent it".
Visible evidence: `نعم` in composer, send control not activated, hovering finger.
Shot: close-up of phone with hand edge; slight over-shoulder if ownership needs context.
Composition: message first; finger second; corridor background third; nothing obscures composer.
Next: near-identical framing with empty composer, so deletion is salient.
Scroll: allow viewer to see the first state before the second. Compare two gutter variations on a phone.
**This is a causal decision chain, not a list of decorative adjectives.**

## Approval response
Present visual decisions in Arabic with succinct explanation of tradeoffs and an ordered panel table plus a vertical-flow synopsis. Do not generate drawings. Save `visual-plan.md` and state `stage2.status=proposed`; request explicit confirmation of frames, angles, composition, spacing, geography and text layout. A correction reopens the gate. The user may approve a group of specified scenes, but never infer approval from silence.
