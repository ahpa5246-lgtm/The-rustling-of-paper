# Webtoon Storyboard Skill

مهارة عملية مبنية على الأيام السبعة المعتمدة من [Webtoon AI Academy](../Webtoon-AI-Academy/). هدفها تحويل نص روائي أو مشهد إلى ستوريبورد Sketch رأسي، عبر قرارات سردية وإخراجية معتمدة قبل توليد الرسوم.

**اقرأ أولًا:** [SKILL.md](SKILL.md). هذه مهارة قابلة للقراءة والاستخدام بواسطة مساعد يدعم ملفات المهارات والوصول إلى GitHub؛ **وجودها في المستودع وحده لا يعني أنها مثبتة تلقائيًا في واجهة ChatGPT**.

## طريقة الاستخدام

أرسل النص القصصي واسم العمل. عند غياب اسم العمل تسأل المهارة عنه بدل اختراعه. يمكن إرسال مشهد منفرد أو فصل كامل. إذا كان النص فصلًا، تقسّمه المهارة إلى مشاهد وتحفظ سياق السابق عند بدء التالي.

تمر كل معالجة عبر ثلاث رسائل أساسية:

1. **التحرير:** التصنيف، الثيمة، وعد القارئ، نبضات القصة، وظائف اللوحات؛ ثم موافقتك.
2. **الإخراج البصري:** حجم اللقطات، الزوايا، التكوين، الأولويات، الاستمرارية، مسافات التمرير؛ ثم موافقتك.
3. **الستوريبورد:** رسومات Sketch بسيطة بعرض **700 بكسل** لكل صورة، وطول بحسب الحاجة، ومقسمة إلى أجزاء مرقمة إذا لزم.

الاعتماد لا يُستنتج من المجاملة؛ يلزم إذن صريح لكل من البوابتين الأولى والثانية. يمكنك طلب أي تعديلات قبل الموافقة. تغيير قرارات معتمدة يعيد البوابة المعنية للمراجعة.

## بنية حفظ الأعمال

يحفظ كل عمل في `webtoon-storyboard-skill/[001] English Work Title/`، يلي ذلك `[002] ...`. الأعمال الطويلة تضع كل فصل في `chapter-001/`، وداخل كل فصل المشاهد في `scene-001/` وما يليها. تُحفظ الخطط المعتمدة والصور والسياق وملاحظات المراجعة. مشهد مستقل يُحفظ تحت `standalone/scene-001/`. لا تُنشأ أعمال افتراضية من دون نص واسم معتمد.
